# Exercício 1 – Conceitos Fundamentais

## a) Qual é a função do AppServer?

O AppServer é o servidor do Protheus. Ele executa os programas, processa as regras de negócio e faz a comunicação entre o SmartClient e o banco de dados.

## b) O que é o RPO?

O RPO é o repositório onde ficam armazenados os programas compilados em ADVPL. Diferentemente do Harbour, que gera um arquivo executável, no Protheus o código compilado é armazenado no RPO.

## c) Para que serve o Configurador (SIGACFG)?

O Configurador é a ferramenta usada para administrar e modificar configurações do Protheus. Nele é possível criar campos e tabelas, alterar títulos, definir campos obrigatórios e configurar permissões sem escrever código.

## d) Qual a diferença entre campo Real e campo Virtual no SX3?

O campo Real é armazenado fisicamente na tabela do banco de dados. O campo Virtual não é gravado fisicamente, sendo usado apenas para exibição, cálculos ou processamento dentro do sistema.
