# Dados e Dicionário

Esta pasta contém os arquivos físicos das tabelas customizadas desenvolvidas para o Trabalho de Conclusão de Curso (TCC) da Jornada DEV START.

## Arquivos

- `ZZ1990.DBF` — Tabela **ZZ1**, utilizada para o controle de fornecimentos e certificados de fornecedores.
- `ZZ2990.DBF` — Tabela **ZZ2**, utilizada para o registro das ocorrências de não conformidade.

## Objetivo

Os arquivos presentes nesta pasta comprovam a materialização física das tabelas customizadas criadas no ambiente TOTVS Protheus, após a configuração do Dicionário de Dados e a execução da criação das tabelas.

As estruturas contemplam:

- campos cadastrados no Configurador;
- índices definidos para pesquisa e ordenação;
- relacionamento entre as tabelas ZZ1 e ZZ2;
- estrutura utilizada pelas rotinas ADVPL desenvolvidas neste projeto.

Esses arquivos complementam a documentação apresentada no README principal e as evidências disponíveis na pasta `evidencias`, demonstrando a implementação da estrutura de dados utilizada pelo sistema.
